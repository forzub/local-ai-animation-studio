# Local AI Animation Studio

Локальный production-стек для создания анимации, изображений, речи, звука и музыки с помощью локальных AI-моделей.

## Цель

Собрать воспроизводимый локальный конвейер:

`script -> storyboard -> keyframes -> animation -> voice -> SFX -> music -> edit -> master`

Приоритеты:

- работа локально;
- модели без облачной prompt-модерации;
- приемлемые лицензии и понятный provenance;
- воспроизводимые workflow;
- пригодность для текущей рабочей станции;
- отсутствие бинарных моделей и больших рендеров в Git.

## Текущая рабочая станция

- CPU: Intel Core i7-9850H, 6C/12T
- RAM: 64 GB
- GPU: NVIDIA Quadro RTX 3000
- VRAM: 6 GB
- OS: Windows 10

Главное ограничение: 6 GB VRAM. Поэтому основной режим — quantization, CPU offload, небольшие разрешения и короткие shots на этапе разработки.

## Репозиторий хранит

- архитектуру;
- состояние проекта;
- manifests и сведения о лицензиях;
- install/bootstrap scripts;
- ComfyUI workflows;
- конфигурацию;
- prompts и метаданные shots;
- небольшие reference assets, когда их лицензия это позволяет.

## Репозиторий НЕ хранит

- веса моделей;
- большие checkpoints;
- cache;
- временные файлы;
- промежуточные и финальные видео/аудиорендеры;
- сторонние бинарные пакеты.

См. `STATE.md` и `docs/ARCHITECTURE.md`.
