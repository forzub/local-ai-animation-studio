# License records

Для каждого реально скачанного checkpoint сюда кладётся отдельная Markdown-карточка или копия/ссылка на лицензию с датой проверки.

Минимум фиксируем:

- model id;
- exact checkpoint filename;
- source page;
- upstream repository;
- license name;
- commercial use;
- output-rights clause, если есть;
- additional restrictions;
- download date;
- SHA-256;
- reviewer notes.

Не считать лицензию базовой модели автоматически лицензией LoRA/fine-tune/checkpoint.
